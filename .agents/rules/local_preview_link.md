# Local Test & Preview Link Rule

เมื่อทำการแก้ไขโค้ด, พัฒนาฟีเจอร์ หรือปรับปรุงส่วนใดของโปรเจกต์เสร็จสิ้นแล้ว:
1. **ต้องแนบลิงก์ทดสอบ Local เสมอ**: แสดงลิงก์คลิกได้ไปยังเครื่อง Local ของผู้ใช้ คือ [http://localhost:8501](http://localhost:8501) ในคำตอบสรุปทุกครั้งโดยอัตโนมัติ
2. แนะนำขั้นตอนการทดสอบฟังก์ชันใหม่หรือผลลัพธ์ที่แก้ไขให้ผู้ใช้ทราบอย่างชัดเจน
