# Local Test & Preview Link Rule (newsl)

## 📌 ขอบเขตการทำงาน (Workspace Scope)
- เมื่อทำงานในโปรเจกต์ **newsl** ให้ดำเนินการแก้ไข พัฒนา และจัดการเฉพาะไฟล์/ทรัพยากรภายในโฟลเดอร์ของ **newsl** เท่านั้น ไม่แตะต้องโปรเจกต์หรือไดเรกทอรีอื่นภายนอก

## 🚫 ข้อห้ามการ Upload GitHub อัตโนมัติ (No Auto GitHub Push)
- **ห้ามทำการ push หรือ upload ขึ้น GitHub โดยพลการ** ขณะกำลังปรับแก้หรือพัฒนาในโปรเจกต์ newsl
- ให้ทำงาน ปรับแก้ และทดสอบผลลัพธ์บนเครื่อง Local ให้เรียบร้อยก่อนเสมอ
- จะทำการ push / upload ขึ้น GitHub ได้ก็ต่อเมื่อผู้ใช้สั่งการอย่างชัดเจนเท่านั้น

## 🔗 ลิงก์ทดสอบ Local สำหรับ newsl (Port 8502)
- เมื่อทำการแก้ไขโค้ด, พัฒนาฟีเจอร์ หรือปรับปรุงส่วนใดของโปรเจกต์ **newsl** เสร็จสิ้นแล้ว:
  1. **ต้องแนบลิงก์ทดสอบ Local เสมอ**: แสดงลิงก์คลิกได้สำหรับโปรเจกต์ newsl บน Port 8502 คือ [http://localhost:8502](http://localhost:8502) ในข้อความสรุปทุกครั้งโดยอัตโนมัติ
  2. แนะนำขั้นตอนหรือฟังก์ชันที่อัปเดตให้ผู้ใช้ทราบอย่างชัดเจน
